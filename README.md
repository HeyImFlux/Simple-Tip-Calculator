# Simple Tip Calculator

A simple Python program that calculates the tip amount and total bill when dining out.

## How It Works

The program asks the user for:

- The total bill amount
- The percentage they want to tip

It then calculates the tip and adds it to the original bill to give the total amount to pay.

## Example

If the bill is $50 and you want to leave a 20% tip:

- Tip: $10
- Total: $60

## Requirements

- Python 3

## How to Run

Run `CalculateTip.py` using Python:

```bash
python CalculateTip.py
```
